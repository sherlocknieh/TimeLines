TimeLines 的目标是做一个**通用的时间线整理与可视化工具**：把一段时间、一组事件组织成一条可读、可比对的时间轴，而不是只服务某一个固定主题。

## 核心理念

- **时间按比例呈现**：纵向距离等于时间距离，空白即代表没有事件的历史区间。
- **多条时间线，共用视野**：每条脉络各占一条时间线，缩放与平移同步，同期事件可以并排对照。
- **可读优先**：标签落在真实日期上，互不遮挡的全部显示，重叠时优先保留级别高的事件；标签默认只显示年份与标题，点选后在原位展开卡片看全文。

## 内置 Demo

<a href="/TimeLines/">/TimeLines/</a> 是用英国与美国的对照历史做的一份 demo，包含 120 个事件，用于验证「多条线索并行、比例对齐、密集处的级别取舍」这些核心表现。它只是示例数据，工具本身不绑定任何主题。

## 显示方案

目前的显示方案是缩放时间轴：所有时间线共处同一块画布，各自一条竖轴，按真实日期排布各自的事件；轴上滚轮缩放、轴外滚轮平移时间，所有线共用同一套视野。时间线数量由 `web/src/lib/dataset.ts` 的 `LANES` 决定，顶部时间线栏还能就地改名与设定起止。
细节与取舍见 [显示方案](/views)，或直接打开 <a href="/TimeLines/">/TimeLines/</a>。

## 通用化路线

当前实现仍围绕 demo 定制，主要待办：

1. **多时间线管理**：在页面上创建、删除时间线，并把名称与起止持久化（目前增删仍需改 `LANES`，改名与起止只在内存中）。
2. **事件编辑**：增删改事件，支持 JSON 导入导出。
