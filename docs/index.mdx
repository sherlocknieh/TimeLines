TimeLines 的目标是做一个**通用的时间线整理与可视化工具**：把一段时间、一组事件组织成一条可读、可比对的时间轴，而不是只服务某一个固定主题。

## 核心理念

- **时间按比例呈现**：纵向距离等于时间距离，空白即代表没有事件的历史区间。
- **一条轴线，多条线索**：不同脉络分居轴线两侧或进入不同泳道，同期事件可以并排对照。
- **可读优先**：标签落在真实日期上，互不遮挡的全部显示，重叠时优先保留级别高的事件；标签默认只显示年份与标题，点选后在原位展开卡片看全文。

## 内置 Demo

<a href="/timeline/">/timeline/</a> 是用英国与美国的对照历史做的一份 demo，包含 100 个事件，用于验证「多条线索并行、比例对齐、密集处的级别取舍」这些核心表现。它只是示例数据，工具本身不绑定任何主题。

## 显示方案

目前的显示方案是缩放时间轴：一条竖直轴按真实日期排布事件，轴上滚轮缩放、轴外滚轮平移时间。
细节与取舍见 [显示方案](/views)，或直接打开 <a href="/timeline/">/timeline/</a>。

## 通用化路线

当前实现仍围绕 demo 定制，主要待办：

1. **任意数量泳道/分组**：现在的左右两栏对应英国与美国，需要抽象为可配置泳道。
2. **多时间线管理**：创建、切换与本地持久化。
3. **事件编辑**：增删改事件，支持 JSON 导入导出。
