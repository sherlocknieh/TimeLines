TimeLines 的目标是做一个**通用的时间线整理与可视化工具**：把一段时间、一组事件组织成一条可读、可比对的时间轴，而不是只服务某一个固定主题。

## 核心理念

- **时间按比例呈现**：纵向距离等于时间距离，空白即代表没有事件的历史区间。
- **一条轴线，多条线索**：不同脉络分居轴线两侧或进入不同泳道，同期事件可以并排对照。
- **可读优先**：密集事件自动避让，并用细线连回真实年份；气泡默认只显示年份与标题，点开再看全文。

## 内置 Demo

[/timeline/](/timeline/) 是用英国与美国的对照历史做的一份 demo，包含 52 个事件，用于验证「多条线索并行、比例对齐、密集避让」这些核心表现。它只是示例数据，工具本身不绑定任何主题。

## 显示方案

目前在同一份数据上实现了四种显示与控制组合：等比泳道、横向甘特、缩放轴、世纪清单。
细节与取舍见 [显示方案](/views)，或直接打开 [/timeline/](/timeline/)。

## 通用化路线

当前实现仍围绕 demo 定制，主要待办：

1. **任意数量泳道/分组**：现在的左右两栏对应英国与美国，需要抽象为可配置泳道。
2. **年份区间自适应**：由数据推导起止年份，不再写死 1200–2030。
3. **多时间线管理**：创建、切换与本地持久化。
4. **事件编辑**：增删改事件，支持 JSON 导入导出。
