title: 显示方案
description: TimeLines 目前实现的缩放时间轴及其交互模型。

同一份 demo 数据（英国 × 美国，120 个事件）在 `/TimeLines/` 下拆成两条并排的竖直时间轴：左侧英国史、右侧美国史，各自只显示本侧事件。两条时间线共用一套时间视野，缩放、平移、线性/对数与基准线始终同步，方便逐段对照。

## 显示

- 两条竖轴并排，时间自上而下；事件按真实日期定位，没有 `date` 的事件按该年 7 月 1 日定位，但只显示年份。
- 英国标签排在轴线左侧、美国标签排在轴线右侧，两条线在中间靠拢；窄屏放不下并排时自动改为上下堆叠，标签统一排在轴线右侧。
- 公元前年份在数据里写作负数，轴上直接显示为 `-2500`。
- 事件带 `end` 时是区间事件：起点到终点之间在轴线一侧画出线段，标签仍锚定起点。终点粒度与起点相同，只写年份就只显示年份；卡片与搜索给出完整的起止日期。
- 同一侧标签落在真实日期上，互不遮挡的全部显示；重叠时优先保留级别高的事件，同级保留较早者。每个标签用一条水平细线连回轴线。
- 事件带 `lvl`（1 主脉 / 2 通史 / 3 细节），只决定重叠时的保留优先级与标签字号，不参与显示筛选：任何缩放都展示全部事件。

## 控制模型

交互边界刻意做得明确：

- **轴上滚轮缩放，轴外滚轮平移时间**：每条轴线附近的 64px 宽热区接管 `wheel` 做缩放；画布其余区域的滚轮则平移时间，浏览长页面时不会误触缩放。
- **轴线可左右拖动**：每条时间线的轴线默认位于面板靠中间的一侧，垂直方向按数据范围居中并适配高度；水平拖动某条轴线只移动它自己，上下拖动空白处则平移时间。
- **悬停轴线放大读数**：指针停在轴线上时，在该条时间线的轴线外侧显示放大的年份与 `YYYY-MM-DD` 日期，并画出贯穿该面板的横向参考线。
- **点击事件原位展开卡片**：点选气泡后，气泡在原处放大为事件卡片，显示精确日期、分类与完整说明；卡片始终夹在所属时间线内，点空白处、关闭按钮或按 `Esc` 收起。
- **搜索定位事件**：工具栏搜索框按标题、年份、分类、描述与时间线匹配事件，支持方向键与回车选择；选中结果会把两条时间轴一起居中并收窄到该事件所属层级，同时展开卡片。
- **任何缩放都不按级别隐藏事件**：全部事件始终参与布局，只有标签在垂直方向发生重叠时才隐藏，重叠时优先保留级别高的事件、同级保留较早者。区间线段不参与标签遮挡筛选，随时展示事件的时间跨度。
- **线性 / 对数两种时间分布**：默认线性，距离与年份严格成正比。「基准线」用来选中一个时间点：线下气泡始终显示选中的日期，拖动它即可选任意日期，线性和对数视图下都能拖；对数模式下这个日期同时是基准日，时间线以它为界向两侧对数压缩。平移到别处、缩放或切换反向时，基准线跟着选中的日期一起移动，选中值不会变。也可在工具栏输入 `YYYY` 或 `YYYY-MM-DD`，或点事件卡片上的准星按钮选中该日期。准星按钮只调整基准与居中，不会改变线性 / 对数分布。
  - 对数可切换天 / 月 / 年对数单位，用来控制靠近基准处被拉开的程度。
  - 对数轴的时间刻度线按固定时间步长生成，疏密直接体现时间被压缩的程度，不做像素级隐藏。
- **今天之后只留少量空间**：线性全览以「今天」为终点，未来最多可平移到今天 +2 年；对数基准靠近今天时，对称展开的未来一侧会留白。
- **可切换反向显示**：默认历史在上、今天在下；切到「反向」后今天位于顶部，历史向下展开。缩放锚点、滚轮与拖动方向随之翻转，线性与对数两种分布都适用。

## 路由

前端使用 `/TimeLines/` 下的 HTML5 history，但只有根页面：打开 `/TimeLines/` 即进入缩放时间轴。应用没有需要单独部署的深层路由，静态托管不需要 SPA 回退规则。

## 取舍

只保留缩放轴，是因为它是四种读法里唯一能同时覆盖「全景」与「精确到日」的方案：事件密度极端不均时靠缩放分离，而不是靠额外的页面布局。英国史与美国史拆成两条并排的时间线，是为了让两条脉络各自成轴、互不挤占标签空间，同时共用一套视野保持可比。等比泳道、横向甘特与世纪清单已经移除，需要时可以基于 `web/src/views/ZoomView.vue` 再扩展。
