这份 demo 用英国与美国的历史事件，演示 TimeLines 想解决的核心问题：**同一段时间里，多条线索如何对齐、如何对照**。它也是[显示方案](/views)中缩放时间轴的示例数据。

- 英国史与美国史各占一条时间线，共处同一块画布、沿横向均匀铺开，纵向距离按真实日期定位；两条线共用缩放与平移，便于逐段对照。
- 轴线起始端的标题节点可直接改名；悬停该节点出现「起 / 止」，例如把英国线限定到 `1066`–`1707`，线段的端点与事件一起收窄。
- 事件标签落在真实日期上，互不遮挡的全部显示；重叠时优先保留级别高的事件，并用水平细线连回轴线。
- 滚轮在轴线上缩放、在轴外平移时间，也可上下拖动空白处平移；任何缩放都展示全部事件，只有标签重叠时才隐藏。
- 点选事件标签会在原位展开事件卡片，点空白处或按 Esc 收起；悬停轴线可读取精确年份与日期。
- 顶部搜索框可搜索事件，选中结果会把时间轴定位到该事件并展开卡片。

demo 数据位于 `web/src/data/events.ts`，与布局逻辑分离；替换它为任意主题的事件集合，即可得到自己的时间线。时间线本身在 `web/src/lib/dataset.ts` 的 `LANES` 里配置，数量不受限制。
