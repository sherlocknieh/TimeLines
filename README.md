# TimeLines 时间线

一个通用的**时间线整理与可视化**工具，目标是让任何人都能把自己关心的一段时间、一组事件，整理成一条可读、可比对、可分享的时间轴。

仓库同时包含文档站点（Blume）和前端应用（Vue 3 + TypeScript + Vite），两者同源构建、同一端口访问。

> 当前内置的 [英国 × 美国等比时间轴](/timeline/) 只是一份 demo，用来演示「同一时间轴上并行展示多条线索」的效果，不代表工具的能力边界。

## 核心理念

- **时间按比例呈现**：纵向距离就是时间距离，一段空白就是一段没有事件的历史。
- **一条轴线，多条线索**：事件分居轴线两侧或分入不同泳道，同一时期的不同脉络可以并排对照。
- **可读优先**：密集处自动避让并连线回真实坐标，气泡默认只显示年份与标题，按需展开细节。

## 通用化路线

当前实现仍是围绕 demo 定制的（固定左右两栏、固定年份区间）。要成为真正的通用工具，需要的抽象：

- 任意数量泳道/分组（当前为英国、美国两栏）——首要目标
- 年份区间由数据自动推导，不再写死 1200–2030
- 时间线的创建、切换与本地持久化
- 事件的增删改，以及 JSON 导入导出
